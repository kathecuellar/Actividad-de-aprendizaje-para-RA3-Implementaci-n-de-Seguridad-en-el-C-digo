# MERN OAuth + JWT Auth Project

## Cómo ejecutar

1. Crear archivos `.env` en las carpetas `server` y `client`:
   - Copia el contenido de `.env.example` y agrega tus claves reales.

2. Instalar dependencias:

```bash
cd server
npm install

cd ../client
npm install
```

3. Ejecutar la aplicación:

```bash
# Inicia el backend
cd server
npm run dev

# En otra terminal, inicia el frontend
cd ../client
npm start
```

4. Asegúrate de tener MongoDB y una app de Google configurada.
